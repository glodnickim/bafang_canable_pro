TSDZ diagnostics (peak-hold)

Values are the PEAK since the last read — so a brief press is catchable. Method: click "Read once" (clears peaks), press the pedal / crank a bit, then click "Read once" again to see the captured peak of each value. Watch which one stays near zero — that is where the assist collapses. Needs firmware 0.0173+ on the TSDZ engine.
